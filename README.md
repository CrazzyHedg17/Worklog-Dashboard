# WorkReport Air

Локальное приложение для учёта рабочего времени, выполненных работ и подготовки отчётов.

## Скачать и запустить

Готовые сборки для Windows x64 находятся в [Releases](https://github.com/CrazzyHedg17/Worklog-Dashboard/releases).

1. Скачайте `WorkReportAir-latest-win64.zip` из последнего релиза.
2. Распакуйте архив в отдельную папку.
3. Запустите `WorkReportAir.exe` из папки `WorkReportAir`.

База пользователя хранится локально в папке `Data`. Перед ручным обновлением сохраните её резервную копию. Архив релиза не содержит персональных данных.

Рядом с архивом опубликована контрольная сумма SHA-256.
